# Eval Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a toggleable Chess.com-style local Stockfish eval bar beside detected Chess.com boards.

**Architecture:** Add a focused eval bar controller in `src/content/evalBar.ts` that owns engine lifecycle, score formatting, and DOM rendering. Wire it through settings, popup UI, and `startChessComBoardDetector`.

**Tech Stack:** TypeScript, Chrome extension storage APIs, Vitest with jsdom, existing `LocalStockfishEngine`.
